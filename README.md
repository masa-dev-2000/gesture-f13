# Gesture Shortcut

Windows 11 向けの .NET 8 アプリです。PC カメラと MediaPipe（Gesture Recognizer / Face Landmarker）で手の形と顔の表情を認識し、割り当てたキーを `SendInput` で送ります。Pocket Deck とは別アプリです。

## 起動

```powershell
cd gesture-f13
dotnet run -c Release
```

配布版は `dotnet publish -c Release -r win-x64 --self-contained false -o publish` で作成し、`publish\GestureF13.exe` を起動します。 .NET 8 Desktop Runtime と WebView2 Runtime が必要です。

起動するとカメラを自動で開始します。最小化中も認識を続けます。×で終了すると長押し中のキーを解除します。カメラ映像は保存しません。

## 割り当て

左手・右手それぞれに、パー、指差し、親指を上、親指を下、ピース、I Love You を割り当てられます。グーは待機姿勢で、キーを割り当てられません。どの形も、信頼度を満たした認識が2フレーム続くと有効になります。待機姿勢を先に認識させる操作は不要です。入力方式は「認識した時に1回押し」または「認識中は長押し」です。初期割り当てはすべて空です。

## 顔の表情

設定画面の「顔の表情でも入力する」をオンにすると、14種類の表情と顔の向きにキーを割り当てられます：口を大きく開ける、にっこり笑う、口をすぼめる、頬をふくらませる、舌を出す、口を左／右に寄せる、眉を上げる、眉をしかめる、片目をつぶる、顔を左／右に向ける、顔を上げる、うなずく。ふつうの顔は待機です。

表情ごとに「何秒保ったら入力するか」（0.1〜5秒）と「反応しにくさ」（0〜100、標準60）を数値で設定できます。似た口の形が同時に強く出ている間は入力しません。カメラが正面からずれている場合は「今の顔の向きを正面にする」で正面を合わせます。

## 画面

設定画面の左列は左手、右列は右手、その下が顔の表情です。メイン画面にはカメラ画像、検出した手の形と顔の表情、押下中のキー、最後に送信したキー、認識処理時間を表示します。実際の手と左右表示が異なる場合は「カメラの左右判定を入れ替える」を変更します。

キーは F1～F24、文字・数字、修飾キー、矢印、メディアキーなどを最大8キーまで組み合わせられます。変更は自動保存され、保存結果を設定画面に表示します。保存先は `%USERPROFILE%\.gesture-shortcut\settings.json` です。旧 v1/v2 設定は初回起動時にバックアップし、旧割り当てを解除して新形式に移行します。左右判定の入れ替え設定は引き継ぎます。以前の `%APPDATA%\Gesture Shortcut\settings.json` も移行対象です。

手や顔を認識できない、信頼度が低い、カメラが止まる、映像や結果が250 ms以上途切れる、またはアプリを閉じると長押しを解除します。送信履歴は Windows への入力送信を示し、対象アプリが受け取ったことまでは保証しません。管理者権限で動くアプリには通常権限からの入力が届かない場合があります。

モデルと WebAssembly は `web/` に同梱しています。MediaPipe パッケージの版は `web/package-lock.json` に記録しています。
